# 🏎️ KART RACER

카트라이더 스타일의 3D 카트 레이싱 게임입니다 (three.js). 별도 설치나 빌드 없이 `index.html` 하나로 실행됩니다.

## 실행 방법
`index.html` 파일을 브라우저로 열면 바로 플레이할 수 있습니다. (PC 키보드 / 모바일 터치 모두 지원)
three.js를 CDN(cdnjs)에서 불러오므로 인터넷 연결이 필요합니다.

## 조작법
| 키 | 동작 |
|---|---|
| `↑` / `W` | 가속 |
| `↓` / `S` | 브레이크 / 후진 |
| `←` `→` / `A` `D` | 조향 |
| `Shift` | 드리프트 (방향키와 함께) |
| `Ctrl` / `Z` | 니트로 부스터 사용 |
| `R` | 재시작 |
| `Esc` | 메뉴 |
| `M` | 소리 켜기/끄기 |

## 게임 특징
- **드리프트 & 부스터 게이지**: 드리프트하면 게이지가 차고, 가득 차면 니트로를 1개 얻습니다 (최대 2개).
- **순간 부스터**: 드리프트를 0.4초 이상 유지한 뒤 떼면 짧은 가속.
- **출발 부스터**: 카운트다운 GO 직전에 가속키를 누르면 빠르게 출발.
- **부스터 패드**: 트랙 위 파란 화살표 패드를 밟으면 가속.
- 3개 트랙 (숲속 서킷 / 사막 캐니언 / 설원 스피드웨이), 3단계 난이도, 5명의 AI 라이벌
- 3랩 레이스, 실시간 순위, 미니맵, 랩 타임, 트랙별 최고 기록 저장
- 3인칭 추적 카메라, 실시간 그림자와 조명, 아스팔트/잔디/모래/눈 텍스처
- 빨강·흰색 연석, 가드레일, 타이어 방벽, 출발 신호등 게이트, 관중석, 광고판
- 스키드 마크, 타이어 연기, 부스터 불꽃, 효과음 (Web Audio)

## Vercel 배포
빌드 과정이 없는 정적 사이트라서 설정 파일 없이 바로 배포됩니다.

1. https://vercel.com/new 에서 GitHub 저장소 `hungungworld/kart-racer`를 Import 합니다.
2. Framework Preset은 **Other**, Build Command와 Output Directory는 비워 둡니다 (루트의 `index.html`이 그대로 서비스됩니다).
3. **Deploy**를 누르면 끝. 이후 `main` 브랜치에 푸시할 때마다 자동으로 다시 배포됩니다.

CLI를 쓰는 경우: 저장소 폴더에서 `npx vercel` (미리보기) 또는 `npx vercel --prod` (프로덕션).
